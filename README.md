# D&D HUB

Web temática dedicada a la organización y búsqueda de partidas online de *Dungeons & Dragons*.

## Autor
- **Nombre:** Jose Alfonso Pereira Sambruno
- **Módulo:** Lenguaje de Marcas en Entornos Web

## Estructura del proyecto
- `index.html`: Página principal con presentación de la plataforma y recursos recomendados.
- `partidas.html`: Tabla con las campañas disponibles, nivel, plazas y días de juego.
- `contacto.html`: Formulario de inscripción para unirse a una campaña.
- `css/styles.css`: Hoja de estilos unificada y adaptable a dispositivos móviles.
- `img/`: Recursos gráficos optimizados en formato WebP.
